Bookmarklet template for converting tampermonkey script on github to bookmarklet for browsers.

Tampermoneky script is basically javascript with a header formating for tampermonkey. 
This bookmarklet lets you directly use the user.js tampermonkey script for the bookmarklet, this automatically updates when the userscipt on github is changed and also helps verify if the script is working on the browser by giving a load notification.

Paste the link to the raw file of the userscript to the template '' to use it.
